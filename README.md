# warden-server

Policy server and admin web panel of **Warden**, a lightweight Endpoint DLP. C++17, runs on Windows, uses the shared rule engine from warden-core to validate policies.

Design: [warden-macos/docs/superpowers/specs/2026-10-20-warden-design.md](https://github.com/OWNER/warden-macos/blob/develop/docs/superpowers/specs/2026-10-20-warden-design.md)
